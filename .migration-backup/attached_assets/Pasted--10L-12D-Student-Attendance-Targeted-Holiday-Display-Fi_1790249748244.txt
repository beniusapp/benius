## Objective

Fix the Student Attendance monthly calendar so that a holiday targeted to a particular class/section is shown only to students whose selected Academic Session enrollment matches that holiday audience.

### Required behavior

For the currently authenticated Student:

A holiday should be treated/displayed as applicable when:

1. It is an `All_School` holiday for the authenticated school; OR
2. It is a targeted holiday whose class/section matches the Student's selected Session enrollment.

A targeted holiday belonging to another class/section must **not** be shown as a holiday for this Student.

## Example

Suppose:

* Student A → Class 5, Section A
* Student B → Class 5, Section B

And the school has:

```text
Holiday:
Date = 15 August
Audience = Class 5 / Section A
```

Then:

* Student A → holiday shown ✅
* Student B → holiday not shown ❌

An `All_School` holiday should continue to appear for both.
