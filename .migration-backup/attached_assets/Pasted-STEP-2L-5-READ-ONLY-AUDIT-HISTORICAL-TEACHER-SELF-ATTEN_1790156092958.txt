==================================================
PRODUCT DECISIONS ALREADY CONFIRMED
==================================================

Attendance policy architecture decisions are now explicitly confirmed:

1. Attendance policy meaning:
   HISTORICAL POLICY SEMANTICS.

   Attendance records must preserve the historical attendance status that was actually determined at the time the attendance event occurred.

2. Existing historical Teacher Self-Attendance:
   KEEP THE STORED HISTORICAL STATUS.

   A later change to the school's current Attendance Policy must NOT reinterpret or rewrite an old Teacher Self-Attendance record's status.

3. Academic Session behavior:
   Attendance Policy remains SHARED ACROSS ACADEMIC SESSIONS.

   A new Academic Session does NOT receive an independent Attendance Policy.
   Do NOT redesign Attendance Policy into a Session-specific policy.

4. Historical Student Attendance target:
   Student Attendance target remains the CURRENT SCHOOL TARGET.

   Historical Student Attendance target display may use the current shared school Attendance Policy.
   Do NOT make Student Attendance target Session-specific as part of this step.

5. Existing global Attendance requirements remain unchanged:
   - Multi-tenant / school isolation is mandatory.
   - Every Attendance operation must remain school/tenant scoped.
   - Attendance records remain Academic-Session scoped.
   - Historical Attendance must remain readable when an older Session is selected.
   - Enrollment is NOT an Attendance prerequisite.
   - Faculty Mapping is NOT an Attendance prerequisite.
   - Any authenticated Teacher in the school can mark Attendance.
   - Attendance uses IST / Asia/Kolkata.
   - Historical Attendance must not be silently changed because current Registry/session configuration changed.
   - Do not introduce unrelated fixes.

==================================================
PRIMARY AUDIT QUESTION
==================================================

Determine exactly whether the current Teacher Self-Attendance implementation can ever reinterpret an old stored Attendance status using the CURRENT Attendance Policy.

We already know from previous audits that current-policy recalculation exists in multiple Teacher Self-Attendance paths.

Now perform a complete READ-ONLY audit to determine the exact historical-status contract required to satisfy decision #2 above.

The key rule we ultimately need is:

    Once a Teacher Self-Attendance record has a stored historical status,
    later changes to the shared current Attendance Policy must NOT change
    the historical meaning of that record.

For example:

    Teacher checks in on Session A.
    Current policy at that time produces PRESENT.

    Later, Admin changes the school's Attendance Policy.

    Reading the old Session A record must still show PRESENT
    based on the historical stored result.

It must NOT recalculate the old record using the new policy.
