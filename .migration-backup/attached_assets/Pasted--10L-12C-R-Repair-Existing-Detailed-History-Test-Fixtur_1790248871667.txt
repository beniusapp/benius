# 10L-12C-R — Repair Existing Detailed-History Test/Fixture

This is a separate, narrowly scoped test-maintenance step.

## Background

During 10L-12C verification, one existing test failed:

```text
server/__tests__/teacher-self-attendance-session-regressions.test.ts
```

Test:

```text
filters detailed history and computes summaries from the same stored statuses
```

Failing assertion:

```text
expect(all.body.statistics.attendanceRate).toBe(100)
```

Actual result:

```text
0.4
```

A read-only investigation established that this is an **existing test/fixture problem**, not a 10L-12C production regression.

The current Teacher Self-Attendance rate contract calculates the rate across the applicable working days in the selected Academic Session through the current IST date.

The fixture currently creates:

* Session beginning 2025-04-01;
* only two Attendance records;
* Present = 1;
* Half Day = 0.5;
* Monday–Friday working days;
* no All_School holidays;
* current calculation period extending through 2026-09-24;
* 388 applicable working days.

Therefore:

```text
(1 + 0.5) / 388 * 100 = 0.3866...
```

which correctly rounds to:

```text
0.4
```

Even a two-record-only calculation would be:

```text
(1 + 0.5) / 2 * 100 = 75%
```

not 100%.
