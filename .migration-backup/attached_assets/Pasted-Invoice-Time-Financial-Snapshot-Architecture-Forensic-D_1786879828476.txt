1. OBJECTIVE

Design a robust Invoice-Time Financial Snapshot architecture.

The goal is that once an invoice is generated, its historical financial meaning is frozen.

For example, if an invoice was generated in August 2026 with:

Original Fee

₹3,500

Concession

₹500

Net Fee

₹3,000

Components

- Tuition — ₹2,200
- Laboratory — ₹300
- Library — ₹500

and the administrator changes the fee structure in September:

- Tuition → ₹2,500
- Laboratory → ₹300
- Library → ₹200
- Concession → different value

the original August invoice and future receipt MUST continue to represent:

- Original Fee: ₹3,500
- Concession: ₹500
- Net Fee: ₹3,000
- Tuition: ₹2,200
- Laboratory: ₹300
- Library: ₹500

The receipt must NEVER reconstruct these historical values from the current fee structure.
