==================================================
1. NON-NEGOTIABLE ATTENDANCE REQUIREMENT
==================================================

Attendance is Academic-Session-specific.

Every Attendance view must represent the Attendance context of the
SELECTED Academic Session.

Historical Attendance must remain visible when a previous Academic
Session is selected, even if the student:

- is no longer active,
- is no longer in the current Student Registry roster,
- has changed class,
- has changed section,
- has been promoted,
- or otherwise has different current Student Registry information.

Student Registry is GLOBAL/CURRENT.

Student Registry must NOT reset, recreate, or become session-specific
when an Academic Session changes.

Do NOT redesign Student Registry.

Do NOT make Student Registry depend on the selected Academic Session.

==================================================
2. CRITICAL HISTORICAL CLASS/SECTION REQUIREMENT
==================================================

Use this exact example during the audit.

Academic Session 2025-2026:

    Ijaz Saikh = Class 9-A

Academic Session 2026-2027:

    Ijaz Saikh = Class 10-B

Student Registry is GLOBAL/CURRENT.

Therefore, after promotion, the current Student Registry may correctly show:

    Ijaz Saikh = Class 10-B

However:

When the user switches Attendance to Academic Session 2025-2026:

    Ijaz Saikh MUST appear in his historical Class 9-A context.

His 2025-2026 Attendance must NOT:

- disappear,
- be hidden,
- move to Class 10-B,
- be interpreted using the current Class 10-B,
- or become inaccessible merely because Student Registry now says Class 10-B.

Likewise:

    Attendance → 2025-2026 → Ijaz Saikh → Class 9-A
    Attendance → 2026-2027 → Ijaz Saikh → Class 10-B

The selected Academic Session determines the historical Attendance
context.

==================================================
3. IMPORTANT ARCHITECTURAL PRINCIPLE
==================================================

There are two separate concepts:

A. CURRENT STUDENT IDENTITY

Student Registry answers:

"Who is this student currently?"

B. HISTORICAL SESSION CONTEXT

Attendance/history answers:

"What was this student's Attendance context during the selected
Academic Session?"

The current Student Registry class/section MUST NOT overwrite the
historical Attendance context.

Do NOT assume the current Student Registry is the historical roster.
