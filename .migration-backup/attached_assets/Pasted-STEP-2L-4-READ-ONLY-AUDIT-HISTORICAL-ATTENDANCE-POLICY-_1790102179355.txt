PROJECT CONTEXT / NON-NEGOTIABLE RULES:

This is a strict multi-tenant school MIS.

1. Every operation must remain isolated to the authenticated school/tenant.
2. Attendance is Academic-Session-specific.
3. Historical Attendance must remain readable when an older Academic Session is selected.
4. Historical Attendance must use the student's historical class/section identity for that selected Session where such identity exists.
5. Student Registry is global/current and must NOT be used to overwrite historical Attendance identity.
6. Enrollment is NOT an Attendance prerequisite/gate.
7. Faculty Mapping is NOT an Attendance restriction.
8. Attendance working-day authority is already finalized by Step 2J:
   A working Attendance day for a particular
   SCHOOL + ACADEMIC SESSION + CLASS + SECTION
   exists when at least one Attendance record exists for that exact
   class/section/date and the date is within the selected Session start/end.
9. Attendance status weights are already finalized by Step 2I.
10. Attendance dates/business dates are IST / Asia-Kolkata date-only values.
11. Step 2L-1 already made Student Attendance use the shared selected Academic Session as its Session authority.
12. Step 2L-2 already fixed Student Monthly Attendance approved-leave Session isolation.
13. Step 2L-3 already fixed archived Teacher self-attendance GET status-healing persistence.
14. Do not undo or reinterpret any of those decisions.
