GOAL
==================================================

Add a secure, tenant-scoped storage lookup for a Teacher account.

Conceptually add:

getTeacherUserByEmailAndSchool(email, schoolId)

This function will be used later by the secure Teacher Forgot Password flow.

==================================================
SECURITY REQUIREMENTS
==================================================

The lookup MUST enforce ALL of the following:

1. users.email = supplied email

2. users.schoolId = supplied validated schoolId

3. users.role = "teacher"

4. users.isActive = true

5. teachers.userId = users.id

6. teachers.schoolId = supplied validated schoolId

Therefore BOTH:

users.schoolId
AND
teachers.schoolId

must match the validated schoolId.

Do not rely on only one of these conditions.

The lookup must NOT accept:

- schoolCode
- tenantId
- client-provided schoolId for authorization

The function receives an already validated schoolId from the caller.

This function itself must enforce school ownership in the database query.
