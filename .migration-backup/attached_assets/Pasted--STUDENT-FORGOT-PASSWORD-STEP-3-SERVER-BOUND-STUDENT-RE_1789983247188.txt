==================================================

Support exactly these stages:

2. PASSWORD_RESET

- stage
- challengeId
- studentId
- schoolId
- createdAt
- updatedAt

Do NOT store:

- plaintext OTP

PASSWORD_RESET should contain:

- flow
- stage
- challengeId
- studentId
- schoolId
- resetToken
- createdAt
- updatedAt

The reset token may exist ONLY inside this server-side recovery session.

Never put resetToken into:

- URL
- query string
- browser localStorage

- client React state
- API response
- HTML
- logs

==================================================
E. SESSION TTL
==================================================

Recovery state must expire automatically.

Use a dedicated recovery TTL:

30 minutes

The validity rule must be explicit.

For example:

now - updatedAt < 30 minutes

At exactly the expiry boundary, treat the recovery state as expired.

Expired recovery state must be cleared.

Do not silently extend an expired recovery session.
