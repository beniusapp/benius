Make ONLY the following small UI enhancement to the Fee Structure cards.

Goal

For fee structures with Monthly or Quarterly frequency, when invoices have been generated, show the latest generated fee period directly beside/below the existing Last Invoices Generated information.

Currently the card shows something like:

Last Invoices Generated
🕐 19 Aug 2026, 03:15 PM

I want it to additionally show:

Latest Fee Period
August 2026

For a quarterly fee, show the appropriate quarter period, for example:

Latest Fee Period
July–September 2026

Important display rules

Monthly

Display the latest generated invoice's actual fee period in a human-readable format.

Example:

- "2026-08-01" → August 2026
- "2026-09-01" → September 2026

Do NOT display raw ISO values such as:

- "2026-08"
- "2026-08-01"

Quarterly

Display the actual latest generated quarterly period as a human-readable date range.

Examples:

- "2026-04-01 → 2026-06-30" → April–June 2026
- "2026-07-01 → 2026-09-30" → July–September 2026
- "2027-01-01 → 2027-03-31" → January–March 2027

Which fee structures should show it?

Show Latest Fee Period ONLY for:

- Monthly
- Quarterly

Do NOT add this new field for:

- Annual
- One-Time

The existing Annual/One-Time card behavior should remain exactly as it is.

Data source

Use the actual latest generated invoice/fee period associated with that fee structure.

Do not calculate or guess the period from today's date.

The displayed period must correspond to the most recently generated invoice.
