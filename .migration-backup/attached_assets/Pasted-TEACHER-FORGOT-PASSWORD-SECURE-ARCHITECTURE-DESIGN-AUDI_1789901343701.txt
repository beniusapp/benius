2. DESIGN TEACHER RECOVERY MAPPING
==================================================

Determine how Teacher Forgot Password should map onto the existing secure infrastructure.

The intended flow is:

Teacher Login
→ Forgot Password
→ School Code + Recovery Email
→ OTP sent through THAT SCHOOL'S configured email provider
→ Verify OTP
→ Set New Password
→ Back to Teacher Login

The tenant boundary MUST be established before selecting the teacher account.

Expected conceptual order:

schoolCode
→ validated school
→ school.id
→ teacher/user lookup constrained by school.id
→ secure recovery challenge
→ school-owned notification configuration
→ school-owned SendGrid credentials
→ OTP delivery

Never use:

email
→ search all schools
→ find first teacher
→ determine school afterward
