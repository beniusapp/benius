7. Implement reliable manual word wrapping

Use PDFKit's actual font metrics to calculate text width.

For every wrapping-enabled cell:

1. Get the actual column width.
2. Apply cell padding.
3. Measure candidate text using:

doc.widthOfString(text)

4. Split on whitespace/word boundaries first.
5. Build lines word-by-word.
6. Only fall back to character-level splitting when a SINGLE token itself is longer than the available width.

Example:

Bank Transfer

must be treated as two words and remain together if the combined width fits.

Do NOT remove the space simply because the string does not fit on the first estimated line.
