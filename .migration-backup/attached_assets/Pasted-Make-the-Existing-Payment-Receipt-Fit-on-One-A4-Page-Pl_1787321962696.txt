Objective

The current Payment Receipt opens correctly through the existing:

Receipt → browser print dialog → Save as PDF

flow, but the receipt currently occupies 2 pages.

I want the same receipt, same design, same data, and same functionality to fit cleanly and professionally on ONE A4 portrait page whenever the content is within normal limits.

Do NOT redesign the receipt.

Do not create a new receipt template.

Do not change the existing receipt data structure, backend logic, API routes, payment logic, invoice logic, or receipt-generation mechanism.

The current receipt is already working correctly. Only optimize its print/PDF layout so it fits on one A4 page.

Do NOT introduce:

3. A4 print configuration

For the print version, make the page explicitly:

@page {
  size: A4 portrait;
  margin: 8mm;
}

Use a compact but professional print layout.

The target should be approximately:

A4: 210mm × 297mm

with the entire receipt fitting inside the printable area.

---

4. Reduce unnecessary vertical spacing

The current receipt has too much vertical whitespace.

For "@media print", carefully reduce:

- section margins
- section padding
- gaps between cards
- header spacing
- table row height
- line-height
- excessive empty areas
- spacing around the signature
- footer spacing

Do this proportionally.

Do not make the receipt look cramped.

The goal is:

«Compact, clean, professional school-finance receipt — not tiny text.»

7. Prevent unnecessary page breaks

Add appropriate print CSS such as:

break-inside: avoid;
page-break-inside: avoid;

for important sections.

However, do not blindly apply "break-inside: avoid" to the entire receipt, because that can cause the browser to push large sections to another page.

Apply it intelligently to:

- section cards
- payment summary
- fee details
- transaction details
- notes
- signature block

The receipt should flow naturally within the single A4 page.

For example, if necessary:

- Main body: approximately 8–9pt
- Labels: approximately 6.5–7.5pt
- Values: approximately 7–9pt
- Section headings: approximately 7–8pt
- Main receipt title: approximately 14–16pt

These are guidelines, not mandatory values.

Use the existing typography as the baseline and reduce only where necessary.

The receipt must remain easily readable when printed.
