NON-NEGOTIABLE PROJECT RULES
==================================================

1. This is a multi-tenant school MIS.

2. Every Attendance operation must remain strictly scoped to:
   authenticated school/tenant + Academic Session + applicable
   class/section/student.

3. Never trust browser-supplied schoolId as the tenant authority.

4. Attendance is Academic-Session-specific.

5. Attendance business dates and application-facing times must use:
   Asia/Kolkata / IST.

6. Student Registry is global/permanent and must NOT be reset or recreated
   when Academic Session changes.

7. Enrollment is NOT an Attendance prerequisite.

8. Faculty Mapping is NOT an Attendance restriction.

9. Any authenticated Teacher belonging to the school can mark Attendance.

10. Step 2I calculation rules must remain exactly unchanged:

    Present = 1.0
    Late = 1.0
    Approved Leave = 1.0
    Halfday = 0.5
    Absent = 0
    Unknown = 0
    Missing/no Attendance row = 0 and tracked separately

11. Step 2J working-day rule must remain exactly unchanged:

    For a particular:
    school + Academic Session + class + section,

    a working Attendance day exists when at least one Attendance record
    exists for that exact class/section/date and the date is inside the
    selected Academic Session startDate/endDate.

12. Sunday/holiday/weekend must NOT automatically exclude a date.
