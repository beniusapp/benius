## PHASE

The application is in the **BUILDING / DEVELOPMENT phase**.

---

# CONFIRMED AUDIT FINDING

The Attendance audit identified this issue:

* `markedAt` is separately formatted/displayed using IST.
* `markedBy` contains a raw ISO timestamp generated using `toISOString()`.
* That raw ISO value represents UTC and is visible to Teachers/Admins.
* This conflicts with the project requirement that application/business/display timestamps use **IST / Asia/Kolkata**.

Known areas include:

* `server/teacher-routes.ts`
* `client/src/pages/teacher-modules/attendance.tsx`
* `client/src/pages/admin-modules/attendance-overview.tsx`

Inspect the current implementation before changing anything.

---

# REQUIRED PROJECT RULE

All application-facing Attendance timestamps must use:

**Asia/Kolkata / IST**

Do not display BST, UTC, browser-local timezone, or another timezone for application/business timestamps.

---

# OBJECTIVE

Remove the raw UTC timestamp from the user-visible `markedBy` Attendance information.

The Teacher and Admin Attendance interfaces must display the relevant timestamp consistently in IST.
