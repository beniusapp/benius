# PROJECT CONTEXT

This is a multi-tenant school MIS.

Permanent requirements:

1. Student Registry is GLOBAL/PERMANENT.
2. Students must not be recreated/reset per Academic Session.
3. Enrollment is Session-specific.
4. Attendance is strongly Academic Session-specific.
5. Tenant/school isolation is mandatory.
6. Any same-school Teacher may mark Attendance unless an existing security requirement explicitly prevents it.
7. Historical Attendance must remain meaningful even if a Student is physically deleted.
8. Archived Sessions must be read-only.
9. Active Session retains the existing 7-day correction/edit behavior.
10. Sunday may be a valid Attendance day when deliberately marked.
11. Application/business/display timestamps use **IST / Asia/Kolkata**.
12. Do not introduce cross-school access or calculations.
