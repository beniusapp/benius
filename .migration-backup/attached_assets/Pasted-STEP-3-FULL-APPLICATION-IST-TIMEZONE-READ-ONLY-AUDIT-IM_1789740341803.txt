==================================================
1. GLOBAL APPLICATION TIMEZONE REQUIREMENT
==================================================

This MIS is an Indian school application.

The canonical application/business timezone is:

Asia/Kolkata
IST
UTC+05:30

Every application-facing business date/time must follow IST.

This applies regardless of:

- server timezone
- Node process timezone
- browser timezone
- user's physical location
- container timezone
- database session timezone

The browser or server's local timezone must NOT silently determine school business dates.

IMPORTANT ARCHITECTURAL RULE:

Absolute timestamps may continue to be persisted using the existing UTC persistence convention.

Do NOT classify UTC timestamp persistence itself as a defect.

The expected architecture is:

1. Business calendar date
   → IST date-only semantics
   → YYYY-MM-DD

2. Absolute timestamp
   → existing UTC persistence convention

3. Business wall-clock time
   → Asia/Kolkata / IST

4. User-facing date/time
   → explicit Asia/Kolkata
