RESOLVER REQUIREMENTS
==================================================

Create a reusable resolver following the repository's existing
storage/type conventions.

Conceptually:

    resolveEnrollmentForStudentSession(
        schoolId,
        studentId,
        sessionId
    )

It must:

1. Verify the Student belongs to the supplied schoolId.

2. Verify the Academic Session belongs to the supplied schoolId.

3. Find the Enrollment using:

       school_id
       student_id
       session_id

4. Return the authoritative enrollment record.

5. Expose:

       class_name
       section_name

6. Do NOT apply any enrollment.status filtering.

Enrollment status rules are intentionally NOT being decided here.

7. Never fall back to:

   - current Student class/section
   - browser class/section
   - teacher assigned class/section
   - Faculty Mapping
   - active session
   - another session

8. Cross-school relationships must never return enrollment data.
