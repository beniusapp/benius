### Required architecture

Every timetable operation must be isolated by:

```text
Authenticated School ID
+
Selected Academic Session ID
```

Different Academic Sessions must be able to have completely different timetables.

Example:

```text
School A
 ├── 2025–26 Timetable
 └── 2026–27 Timetable
```

Changing the 2026–27 timetable must NOT change the 2025–26 timetable.
