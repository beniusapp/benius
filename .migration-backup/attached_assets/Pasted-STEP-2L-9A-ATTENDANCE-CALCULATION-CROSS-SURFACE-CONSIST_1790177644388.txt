ESTABLISHED ATTENDANCE CALCULATION CONTRACT FROM STEP 2L-8B:

A. APPLICABLE / WORKING DATE
A date is applicable when there is at least one Attendance row for the exact:
School + Academic Session + Class + Section + Date

The date must remain within the inclusive Academic Session boundaries.

This is RECORD-DRIVEN and CLASS-WIDE.

A particular Student does not need an Attendance row for the date to be applicable to that Student.

B. SUNDAY
Sunday is NOT automatically a working day.

A deliberately stored Sunday Attendance row remains valid Attendance evidence and its stored status is calculated normally.

C. HOLIDAY
A holiday alone does not create an applicable Attendance date.

An existing Attendance row on a holiday remains valid calculation evidence.

The existing direct-marking restriction for All_School holidays must remain unchanged unless a later explicit product decision changes it.

D. STATUS WEIGHTS

Present = 1
Late = 1
Leave Attendance row = 1
Half Day = 0.5
Absent = 0
Missing/no Student row on applicable date = 0
Unknown status = 0

Missing remains distinct from explicit Absent.

E. DENOMINATOR

Denominator = number of applicable record-evidenced dates.

Percentage:

weighted attendance / applicable dates × 100

Rounded to one decimal place.

Zero applicable dates = 0.

F. APPROVED LEAVE WITHOUT ATTENDANCE ROW

An approved leave application by itself does NOT create an applicable Attendance date.

If the class date is already applicable but the Student has no Attendance row, the Student is Missing, not Leave.

Monthly calendar display may separately show an Approved Leave label; that presentation must not be confused with the shared percentage calculation contract.
