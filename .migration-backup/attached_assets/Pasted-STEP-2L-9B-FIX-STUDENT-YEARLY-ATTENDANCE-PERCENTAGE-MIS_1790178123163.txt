ESTABLISHED STUDENT ATTENDANCE CONTRACT:

Applicable date:

* A date is applicable when there is at least one stored Attendance row for:
  School + Academic Session + Class + Section + Date
* Date must be within inclusive Academic Session boundaries.
* This is record-driven and class-wide.

Status weights:

* Present = 1
* Late = 1
* Leave Attendance row = 1
* Half Day = 0.5
* Absent = 0
* Missing/no Student row on an applicable date = 0
* Unknown = 0

Percentage:
weighted attendance / applicable dates × 100

Round to ONE decimal place.

Zero applicable dates:
return/display 0 according to the existing canonical calculation behavior.

KNOWN BUG:

The Student yearly table in:

client/src/pages/student-attendance.tsx

currently independently calculates its displayed percentage around:

client/src/pages/student-attendance.tsx:775–789

The current expression effectively uses:

(Present + 0.5 × Half Day + Leave) / Working Days × 100

It incorrectly omits Late and rounds to a whole number.

Example:

If an evidenced month contains:

* Late = 1
* Working Days = 1

Canonical result:
100.0%

Current yearly table:
0%

This is a real calculation/display mismatch and must be corrected.
