The current PDF contains too many columns squeezed into a single horizontal row.

Although the information is technically present, on a phone or normal PDF viewer the text is extremely small and difficult to read.

The current PDF looks more like a database dump than a professional school financial report.

Improve the layout so that it looks like an official school fee ledger/accounting report.
