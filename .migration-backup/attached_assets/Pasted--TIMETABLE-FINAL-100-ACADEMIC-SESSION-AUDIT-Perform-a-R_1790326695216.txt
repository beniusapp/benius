## SESSION ISOLATION

Verify these scenarios:

### Scenario A

Session A timetable exists.

Session B timetable exists.

Can Session A read Session B?

Must be:

```text
NO
```

### Scenario B

Create/update/delete in Session A.

Can it affect Session B?

Must be:

```text
NO
```

### Scenario C

Same class + section + day + period exists in Session A and Session B.

Must be allowed.

Example:

```text
Session A
Class 5 / A / Monday / Period 1

Session B
Class 5 / A / Monday / Period 1
```

These must NOT conflict.

### Scenario D

Period 1 can have different timing in different Academic Sessions.

Must be allowed.

Example:

```text
2025–26
Period 1 = 8:00–8:40

2026–27
Period 1 = 8:30–9:10
```

These must NOT conflict.

## MULTI-TENANT ISOLATION
