# NEW CONFIRMED PRODUCT DECISION

BENIUS Student Attendance uses:

## NOT MARKED ≠ ABSENT

A Student whose attendance has not yet been submitted must NOT automatically be treated as Absent.

For Daily Presence percentage:

```text
Present / Marked Applicable Attendance
```

An eligible Student with no attendance mark is tracked as:

```text
Not Marked
```

and is NOT included in the percentage denominator.

```text

```

---

# DAILY PRESENCE — MARKED POPULATION

For the percentage calculation, use eligible Students who actually have an applicable attendance status recorded for that date.

Conceptually:

```text
Eligible Student
      ↓
Attendance record exists?
      ↓
YES → use recorded attendance status in existing BENIUS calculation
NO  → Not Marked
```

An eligible Student with no attendance record:

```text
Not Marked
```

must NOT automatically become:

```text
Absent
```

and must NOT reduce the Daily Presence percentage.

---

# INACTIVE STUDENTS

Inactive Students must be excluded completely from LIVE Daily Presence.

Example:

```text
students.is_active = false
```

means the Student must NOT contribute to:

- Present count
- Absent count
- Daily Presence denominator
- Daily Presence percentage
- Not Marked count
- live eligible population

even if an old attendance record exists for that date.

---

# INACTIVE ENROLLMENT

Likewise:

```text
students.is_active = true
BUT
selected-session enrollment.status != Active
```

must not contribute to live Daily Presence.

---

# EXISTING INELIGIBLE ATTENDANCE ROWS

If an inactive/ineligible Student has an Attendance record for the requested date, that row must not affect the LIVE Daily Presence calculation.

Eligibility must be established first.

Then attendance status is associated with eligible Students.

Do NOT start from attendance rows and assume every row is eligible.
