We have now approved the following business requirement for the School MIS Attendance system.

## APPROVED BUSINESS REQUIREMENT

Each school/tenant must be able to configure which days of the week are normal working days.

Default:

* Monday = Working
* Tuesday = Working
* Wednesday = Working
* Thursday = Working
* Friday = Working
* Saturday = Non-working
* Sunday = Non-working

But a school may enable Saturday and/or Sunday as working days.

Example:

School A:
Monday–Friday = working
Saturday = non-working
Sunday = non-working

School B:
Monday–Saturday = working
Sunday = non-working

The configuration MUST be school/tenant-specific.

---

## ATTENDANCE BEHAVIOR

The working-day configuration determines whether Teacher Self-Attendance is expected on a particular date.

If the weekday is NOT configured as a working day:

→ Teacher attendance is not required.
→ The date is excluded from the Teacher Self-Attendance rate denominator.

If the weekday IS configured as a working day:

→ Teacher attendance is expected.
→ If the teacher has no attendance record, the date is treated as Absent for rate calculation.
→ If the teacher checks in, the EXISTING Attendance Policy timing logic determines the stored status.

Do NOT create a new Saturday-specific attendance status.

---

## EXISTING ATTENDANCE POLICY MUST REMAIN RESPONSIBLE FOR TIMING

For a configured working day, including Saturday/Sunday when enabled, continue using the existing Attendance Policy rules:

* Expected Arrival
* Grace Period
* Half-Day Cutoff
* School End Time
* Present
* Late
* Half Day
* Leave

Do not duplicate or replace the existing timing/status engine.

---

## HOLIDAY PRIORITY

A declared school holiday overrides the normal working-day configuration.

Example:

Saturday is configured as a working day.

But Principal/Admin declares that Saturday as a school holiday.

Result:

→ Holiday
→ Attendance not required
→ Date excluded from Teacher Self-Attendance rate

The holiday must be evaluated using the existing school calendar/holiday mechanism where possible.

Do not create a second holiday system.

---

## TEACHER SELF-ATTENDANCE RATE CONTRACT

Use the following approved business rules:

1. Rate period:
   Selected Academic Session start date → today in IST.

2. Working day:
   Determined by the school's configured weekday working-day settings.

3. Holiday:
   Excluded.

4. Future date:
   Excluded.

5. Working day with no Teacher Self-Attendance record:
   Absent.

6. Status weights:
   Present = 1.0
   Late = 1.0
   Half Day = 0.5
   Leave = 0
   Absent = 0

7. Percentage:
   Earned attendance / applicable working days × 100.

8. Rounding:
   1 decimal place.

9. Zero applicable days:
   0.0%.

10. Academic Session boundaries:
    Strictly enforced.

11. Timezone:
    IST / Asia/Kolkata.
