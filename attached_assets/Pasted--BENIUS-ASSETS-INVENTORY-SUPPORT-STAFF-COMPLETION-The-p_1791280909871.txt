# PRODUCT DECISION

Assets & Inventory uses a parent-only Support Staff permission.

```text id="zk1j6w"
Assets & Inventory = GRANTED
→ Full normal Principal/Admin operational functionality

Assets & Inventory = NOT GRANTED
→ Zero access
```

When granted, Support Staff must be able to:

- View assets
- Add assets
- Edit assets
- Delete assets

subject to the same normal validation and security rules as Principal/Admin.

- View → PASS

- Delete → FAIL for Support Staff

- weaken audit integrity.
