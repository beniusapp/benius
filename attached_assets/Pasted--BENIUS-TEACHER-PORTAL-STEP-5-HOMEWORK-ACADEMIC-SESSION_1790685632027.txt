# PERMANENT HISTORICAL SESSION RULE

This rule is now explicit for BENIUS:

**ACTIVE Academic Session**
→ reads allowed
→ existing permitted writes allowed

**PREVIOUS / INACTIVE Academic Session**
→ historical reads allowed
→ STRICTLY READ-ONLY

For session-specific Teacher Homework data, an inactive Academic Session must NOT allow:

- create homework
- edit homework
- delete homework
- change homework
- upload/replace/remove homework attachment
- modify Student submission state
- grade/review/change submission if such actions exist
- any other persisted Homework mutation

A historical write must NEVER silently redirect to the active Academic Session.

Backend enforcement is mandatory.

Do not rely only on disabled UI controls.
