# BENIUS Academic Result & Promotion System — Full Remediation

Perform a **complete audit and implementation** of the Academic Policy, Exam Result, Promotion, Attendance, Multi-Tenant, and Academic Session logic.

## Core Rule — Non-Negotiable

BENIUS is a **multi-tenant school application**.

Every academic operation must always use:

`Authenticated School + Academic Session + Student + Authoritative Class/Section + That School's Policy`

**Never use another school's policy, data, marks, attendance, or session.**

The final result must guarantee:

`Teacher Result = Admin Result = Student Result = Backend Result = Promotion Ledger Result = Final Promotion Result`

Remove/stop using independent frontend calculation logic.

The frontend must **display backend-calculated results only**.

The engine must handle:

* Remarks
* Pass/fail
* Grade-based passing
* Percentage-based passing
* Failed subject count

## 3. Every School Must Use Its Own Policy

Policy resolution must always be:

```text
Authenticated School
→ Verified Session
→ Verified Student
→ Authoritative Class/Section
→ That School's Academic Policy
→ That School's Exam/Promotion Policy
→ Calculate Result
```

Never:

* Use global policy
* Use another school's policy
* Use hardcoded fallback values
* Use the first matching policy silently

For every class, require **exactly one applicable policy**.

Return explicit errors:

```text
POLICY_NOT_CONFIGURED
POLICY_CONFIGURATION_AMBIGUOUS
POLICY_CONFIGURATION_INCOMPLETE
INVALID_POLICY_WEIGHT_CONFIGURATION
```

Do not calculate an authoritative Pass/Fail if policy resolution fails.

## 5. Fix Grade Resolution


Detect and reject:

* Gaps
* Invalid ranges
* Overlapping ranges
* Duplicate applicable rules

Support:

```text

Grade-based
Both
```

If grade-based passing is configured, pass/fail must use:

```text

```

Reject invalid scores.

Do not:

* Convert invalid marks to 0
* Use `parseInt` when decimals are supported
* Convert total marks of 0 into 100
* Convert pass marks into default values
* Accept negative marks
* Accept marks above maximum

Validate:

```text

marks <= totalMarks
totalMarks > 0
```

Define one consistent decimal and rounding policy.

### Teacher Decision

### Admin Override

### Final Decision

Approved decision for execution.

### Promotion Execution

Actual student promotion.

Manual decisions must **never overwrite the original policy verdict**.

Store audit information for each.
