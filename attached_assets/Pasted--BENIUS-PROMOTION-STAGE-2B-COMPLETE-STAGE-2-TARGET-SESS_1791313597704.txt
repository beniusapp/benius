# FINAL STAGE 2 PRODUCT CONTRACT

Promotion prepares a Student's placement for a **future/target Academic Session**.

It must NOT immediately change the Student's current placement.

Example:

```text
SOURCE SESSION — 2026–27 (ACTIVE)

Student Registry:
MIS-0003 → Class 2/A, Roll 3

Source Enrollment:
2026–27 → Class 2/A, Roll 3
```

Admin promotes the Student to:

```text
TARGET SESSION — 2027–28

Class 3/A
Roll = unassigned/null if no target roll is provided
```

After successful Promotion:

```text
Student Registry
2026–27 current placement
→ Class 2/A, Roll 3
→ UNCHANGED

Source Enrollment
2026–27
→ Class 2/A, Roll 3
→ UNCHANGED

Target Enrollment
2027–28
→ Class 3/A
→ CREATED

Promotion History
source_session_id = 2026–27
target_session_id = 2027–28
```

Only Stage 3 will later synchronize Student Registry when the target session becomes active.
