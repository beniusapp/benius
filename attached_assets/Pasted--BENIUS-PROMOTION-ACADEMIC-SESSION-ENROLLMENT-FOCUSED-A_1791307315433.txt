# PROMOTION TARGET BEHAVIOR

Promotion is different from ordinary Student Registry Edit.

Example:

Current session:

```text
2026-2027

MIS-0003
Class 2/A
Roll 3
```

Promotion to next session:

```text
2027-2028

Class 3/A
Roll 5
```

The required conceptual result is:

```text
Student Registry CURRENT placement
→ Class 3/A, Roll 5

Enrollment history:

2026-2027
→ Class 2/A, Roll 3
→ PRESERVED

2027-2028
→ Class 3/A, Roll 5
→ NEW enrollment
```

Promotion must NEVER rewrite:

```text
2026-2027 enrollment
```

to:

```text
Class 3/A
```

Historical Academic Session enrollment must remain historical.
