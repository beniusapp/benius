# BENIUS EXAMINATION — TEACHER MARKS ACCESS POLICY
## READ-ONLY AUDIT BEFORE STAGE 2B
### DO NOT IMPLEMENT YET

I want to simplify the Teacher Examination → Add Marks workflow.

Currently, when a Teacher tries to save marks for a class/section/subject outside their assigned teaching subjects, BENIUS displays:

"You are not assigned to enter marks for this subject, class, and section."

I do NOT want this assignment restriction for Add Marks.

### MY PROPOSED BUSINESS RULE

Any authenticated, active Teacher belonging to the same school should be able to add or edit examination marks for any valid class, section and subject in that school's active Academic Session.

Teacher assignment should NOT be required for marks entry.

This should behave similarly to the broader same-school Teacher access model used in other BENIUS modules, while preserving examination-specific academic safeguards.

Before implementing, audit whether this rule can be introduced safely.
