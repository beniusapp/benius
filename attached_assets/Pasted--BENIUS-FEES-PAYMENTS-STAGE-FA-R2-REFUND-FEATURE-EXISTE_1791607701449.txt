## 6. Financial Analytics impact

The previous audit found:

- Gross Collected uses payment records.
- Net Collected currently equals Gross Collected.
- Financial Analytics outstanding omits processed refunds.
- Aging drill-down includes processed refunds.
- Ledger transaction detail uses refund-aware outstanding.
- Student Fees has inconsistent outstanding calculations after processed refunds.

Investigate:

1. If new refund initiation is disabled, do these inconsistencies remain relevant to existing historical refunds?
2. Can all normal no-refund financial calculations remain unchanged?
3. Which refund-related displays can safely be hidden?
4. Which refund-related calculations must remain for historical financial correctness?
5. Would removing refund-related code affect Razorpay payment verification?
6. Would removing refund-related webhooks affect other payment event processing?
7. Would disabling new refunds change existing invoice statuses or balances?

**Do not change Net Collected, Outstanding, Collection Efficiency, or any other formula.**
