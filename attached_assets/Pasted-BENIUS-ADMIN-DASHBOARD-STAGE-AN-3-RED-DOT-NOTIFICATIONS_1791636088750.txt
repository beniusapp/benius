OBJECTIVE:

Verify exactly which Admin Portal modules and submodules have red-dot or numeric notification badges, how they work, and how they connect to Action Required.

TARGET MODULES:

1. COMPLAINT HUB
   - Private Teacher Messages / Private Complaints
   - Student & Staff Grievances

3. APPROVAL CENTER
   - Gallery Hub
   - E-Book Library

4. LEAVE REQUESTS
   - Teacher Leave
   - Student Leave
   - Leave Approval History

Use actual implemented module and submodule names when they differ from the names above.

PART A — VERIFY PARENT AND SUBMODULE BADGES

For each target module and submodule, report:

- Does a red-dot or numeric badge exist on the parent module?
- Does a badge exist on its sidebar/tile submodule?
- Does a badge exist inside the opened submodule?
- What exact event triggers it?
- What API/query supplies it?
- Is it a pending-action count or an unread/unseen notification?
- Does it disappear when clicked?
- Does it disappear only after the underlying action is resolved?

Do not confuse an internal page count with a navigation notification badge.

PART B — CLICK-TO-DISMISS REQUIREMENT

The desired behavior is:

When the Admin clicks a module or submodule notification, the corresponding unread red dot should disappear from that submodule and its parent, provided no other unread notifications remain.

IMPORTANT:

- Clicking must NOT approve leave.
- Clicking must NOT resolve complaints.
- Clicking must NOT approve Gallery/E-Books.
- Clicking must NOT delete records.
- Clicking must NOT alter pending-action counts.

Check whether BENIUS already stores unread/seen state.

If not, explain the smallest safe approach to introduce click-to-dismiss red dots separately from actionable pending-work counts.

Also verify what happens when a new pending item arrives after the Admin has already opened that module.

PART C — ACTION REQUIRED

Verify the Stage AN-2 implementation.

Check:

- Teacher Leave → correct submodule.
- Student Leave → correct submodule.
- Gallery Hub → correct submodule.
- E-Book Library → correct submodule.
- Complaints → correct owning module/submodule.

For each source, verify whether Action Required has an independent actionable count and whether clicking the item navigates correctly.

IMPORTANT:

Action Required should continue displaying unresolved work even after a notification is marked seen.

Do not clear Action Required merely because the Admin opened a module.
