# BUG 1 — INACTIVE STUDENTS APPEAR IN LIVE ATTENDANCE

The audit confirmed that the live Teacher Attendance roster currently selects students from session enrollments but does not require:

```text
students.is_active = true
```

and does not enforce the active enrollment state.

This caused inactive students:

- MIS-0004
- MIS-0006
- MIS-0007

to remain visible and markable in Class 1/A.

## CORRECT LIVE ATTENDANCE ELIGIBILITY

For normal/live Student Attendance, a Student is eligible only when ALL applicable conditions are true:

```text
authenticated school
+
selected Academic Session
+
matching enrollment for selected session
+
matching Class
+
matching Section
+
students.is_active = true
+
enrollment is Active
```

Implement this as the canonical live-attendance roster eligibility rule.

Do not use current `students.class/section` for session-specific placement when a selected-session enrollment is available.

The selected-session `enrollments` row remains authoritative for academic placement.

## Teacher Attendance roster GET

## Attendance POST/write validation

Do not rely on UI hiding for security or correctness.
