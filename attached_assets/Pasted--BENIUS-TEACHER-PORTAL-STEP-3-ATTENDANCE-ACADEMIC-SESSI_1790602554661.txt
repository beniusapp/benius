When Teacher Attendance loads Students for a class/section in a selected Academic Session, Student placement should come from:

`enrollments`

using:

authenticated Teacher's school
+
Student
+
selected Academic Session

Do NOT use only current:

`students.class`
`students.section`
`students.roll_number`

for historical session rosters.

Example:

Student Arif:

2025–26:
Class 7 / Section A / Roll 12

2026–27:
Class 8 / Section B / Roll 8

Class 7 / Section A / Roll 12

not the Student's current Class 8 placement.

Preserve permanent identity fields from `students`.

Use session placement from `enrollments` where attendance cohort/placement is session-dependent.
