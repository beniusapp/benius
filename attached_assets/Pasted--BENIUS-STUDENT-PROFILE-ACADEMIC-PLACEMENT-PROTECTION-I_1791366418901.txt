# CONFIRMED PRODUCT DECISION

The following fields are **school-assigned academic placement fields**:

- Class
- Section
- Roll Number

Students must NOT be allowed to:

- edit them
- propose changes to them
- submit changes to them through Profile Verification
- modify them through a manually crafted Student Profile API request

Students may only VIEW these fields.

Official placement must continue to be controlled through authorized school/Admin workflows.

---

```text id="1xnp2a"

```

Therefore Verification Details shows:

`10`

while:

Student Profile → `—`

The submitted `10` is NOT an official school-assigned Roll Number.

Do NOT promote/copy that value into official placement.
