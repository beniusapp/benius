    student_id + date

==================================================
SETTLED FUTURE ATTENDANCE CONTRACT
==================================================

Student Attendance identity:

    school_id
    + session_id
    + student_id
    + date

Session:

- server-authoritative
- authenticated school's active Academic Session
- browser cannot select write session
- historical sessions read-only
- Attendance must retain session identity

Enrollment:

- Attendance requires:
    school_id + student_id + session_id
- class_name and section_name come from enrollment
- browser class/section is not authoritative
- historical Attendance must not move when placement changes

Tenant isolation:

- school_id comes from authenticated tenant context
- browser school_id is never trusted
- Student, Teacher, Session and Enrollment relationships must be tenant-safe

Canonical persisted Student Attendance statuses:

    present
    absent
    late
    halfday

Currently unresolved:

    leave

Do not invent a leave policy.

Edit contract:

- initial creation = edit_count 0
- changed status = +1
- unchanged status = no-op
- maximum Teacher changes = 3
- cap enforcement must be atomic
- seven-day edit window uses IST calendar arithmetic
- Admin override/correction behavior remains unresolved

Teacher authorization:

Current behavior:

    authenticated same-school Teacher

Faculty Mapping / legacy assignment restriction remains a product decision.

Do not add assignment restrictions in this audit.
