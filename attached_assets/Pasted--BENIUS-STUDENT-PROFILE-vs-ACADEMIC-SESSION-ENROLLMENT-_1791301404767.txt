# CONFIRMED EXAMPLE

Development Student:

```text
MIS-0003 / student3mis
```

Student Registry currently displays:

```text
Class 2
Section A
```

But the selected Academic Session is:

```text
2026–2027
```

and the previous audit confirmed the Student's selected-session enrollment is:

```text
Class 2
Section B
```

Therefore:

```text
Student profile/current placement = 2/A

Selected-session enrollment       = 2/B
```

Teacher Attendance correctly uses selected-session enrollment and therefore treats MIS-0003 as:

```text
2/B
```

So selecting Class 2/A in Teacher Attendance correctly finds no eligible Student.

The question is:

# WHY DID THE STUDENT PROFILE AND ACTIVE-SESSION ENROLLMENT BECOME DIFFERENT?
