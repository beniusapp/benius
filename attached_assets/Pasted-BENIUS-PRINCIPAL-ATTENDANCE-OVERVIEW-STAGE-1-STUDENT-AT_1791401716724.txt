==================================================
ESTABLISHED BENIUS RULES — DO NOT CHANGE
==================================================

1. Multi-tenant isolation is mandatory.

School A must never read or calculate with School B Students, Enrollments, Attendance, Sessions, Teachers, or other data.

2. Academic Session isolation is mandatory.

Attendance data must remain scoped to:

authenticated school
+
explicitly selected Academic Session
+
selected attendance date

Do not silently mix sessions.

3. For LIVE/CURRENT Attendance eligibility:

A Student is eligible only when:

- Student belongs to authenticated school
- students.is_active = true
- Student has an Enrollment in the explicitly selected Academic Session
- Enrollment belongs to the same school
- Enrollment status = Active
- class/section comes from that selected-session Enrollment

This is the same eligibility principle already established for the corrected Teacher Web live Attendance roster.

4. HISTORICAL ATTENDANCE MUST BE PRESERVED.

Do NOT apply today's Student active status in a way that erases legitimate historical attendance.

Example:

A Student attended school during an old Academic Session and was later deactivated.

That Student's legitimate old Attendance must remain visible in that historical session.

Therefore:

ACTIVE/CURRENT SESSION
→ use live eligibility:
Active Student + Active selected-session Enrollment.

ARCHIVED/HISTORICAL SESSION
→ preserve historical Enrollment/Attendance population according to that historical session.
→ current Student deactivation must NOT erase historical Attendance.
→ historical academic content remains read-only.

Do not invent a new historical rule silently.

If the existing historical population logic needs adjustment to safely preserve historical records, explain exactly what you are doing.

5. Admin Attendance "Assigned" Teacher column behavior is intentional.

Do NOT change it.

It may show current Teacher assignments.

6. Teacher Self-Attendance historical stored status is authoritative.

Do NOT recompute old Teacher attendance using current Attendance Policy.

7. IST / Asia-Kolkata remains the business/display timezone.

8. Promotion / Academic Session Stage 3 behavior must remain unchanged.

9. Mobile is frozen.

Do NOT modify:
artifacts/benius-mobile/

Do not redesign Mobile APIs.
