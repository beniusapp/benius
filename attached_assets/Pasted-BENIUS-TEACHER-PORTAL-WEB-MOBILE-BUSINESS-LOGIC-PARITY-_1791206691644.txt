We have identified an important architectural concern:

The BENIUS Web application is the established product/source of truth.

The Mobile application is intended to replicate the same BENIUS functionality using the same backend/database.

Mobile must NOT independently invent different business rules.

The ideal architecture is:

BENIUS PRODUCT RULE
→ SHARED BACKEND ENFORCEMENT
→ WEB + MOBILE
→ SAME BUSINESS RESULT

Web and Mobile may have different UI implementations and authentication mechanisms, but equivalent operations should follow the same business rules unless a difference was explicitly designed.

---

IMPORTANT PRODUCT DECISIONS ALREADY CONFIRMED

Treat these as authoritative.

ATTENDANCE

Any authenticated Teacher belonging to the school may mark Student Attendance for any valid class/section within that SAME school.

Teacher class assignment is NOT required for Attendance.

School A Teacher
→ School A valid class → ALLOWED.

School A Teacher
→ School B → REJECTED.

Academic Session and Student enrollment isolation still apply.

---

HOMEWORK

Any authenticated Teacher belonging to the school may give Homework to any valid class/section/subject within that SAME school.

Teacher assignment is NOT required.

School/tenant and Academic Session isolation remain mandatory.

---

CLASSWORK

Same rule as Homework.

Any authenticated Teacher belonging to the school may give Classwork to any valid class/section/subject within that SAME school.

Teacher assignment is NOT required.

---

EXAMINATION

Different rule.

Examination operations ARE Teacher-assignment restricted according to the existing BENIUS Examination design.

A Teacher must have the appropriate existing class/section/subject permission for the Examination operation.

Do NOT change this rule during the audit.

Step 12B was intentionally skipped for now, so the known Web Examination assignment-enforcement gap remains OPEN.

---

STUDENT LEAVE

Preserve the existing BENIUS Student Leave permission model.

Do NOT reinterpret Student Leave as school-wide Teacher access.

Step 12A hardened the legacy Student Leave route.
