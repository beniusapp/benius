# 4. SIMPLE RESULT DISPLAY CONTRACT

I want the following consistent behavior.

### COMPLETE RESULT

When all required marks and components are available:

- Show the correct calculated percentage.
- Show the correct grade.
- Show the correct evaluated subject failures.
- Show the correct result status.
- Use the same configured examination policy.

### INCOMPLETE RESULT

When required examination marks or components are missing:

- Show `Incomplete / Pending Result`.
- Do not invent missing marks.
- Do not silently treat missing components as zero.
- Do not normalize partial marks into a final complete result.
- Do not display a final weighted percentage or grade as if the result were complete.
- Do not automatically mark the Student Promoted or Retained.

### ZERO MARKS

A legitimately recorded zero must remain a valid evaluated score, not be confused with a missing score.

### ABSENT

Explicit Absent must retain the existing authoritative engine's semantics.

### ACADEMIC SESSION

Every result must use the exact selected Academic Session and authenticated School.

Historical results must use historical session Enrollment, not current Student Registry placement.

Archived sessions remain read-only.
